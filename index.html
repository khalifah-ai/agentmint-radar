How it works

1

Connect a wallet holding an Agent ID

AgentMint Radar reads your balance on the Agent ID contract (0x60B9…8B022F). Holders unlock check-in and signals; everyone can browse the radar and live counts.

2

Check in once a day

Each check-in is a transaction on the AgentMintRadar contract. It records your streak and total, and adds to the global counter above. Days are counted in UTC.

3

Signal the mints you care about

Signaling writes keccak256(mint contract address) to the radar contract. Signal counts are public and live, so projects and other agents can see which free mints the Agent ID community is actually watching.
